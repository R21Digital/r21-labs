A read-only MCP server over Fantasy Tabletop Helper's Postgres. An assistant
gets campaigns, sessions, notes and codex entries scoped by row-level security,
so there is one credential boundary instead of a shared service password.

Verified against the GitHub API on 2026-08-22: public, MIT.
