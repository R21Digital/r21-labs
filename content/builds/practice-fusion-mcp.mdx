An open-source, FHIR-first, read-only MCP server for Practice Fusion. When we
built it, the only existing Practice Fusion MCP wrote through the UI layer;
nothing gave an assistant structured, auditable, read-first access.

The access layer is a standalone FHIR module with no MCP knowledge, so a future
app can import it directly. Every tool invocation logs an audit record with no
free-text PHI in it.

Verified against the GitHub API and the npm registry on 2026-08-22: public,
MIT in both places, latest npm release 0.4.0.
